# ECHO LABYRINTH

Игра запускается как статический сайт и совместима с GitHub Pages.

## Публикация

1. Загрузите содержимое этой папки в репозиторий (файл `index.html` должен лежать в корне).
2. Откройте **Settings → Pages**.
3. В поле **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните настройки и откройте выданный GitHub Pages URL.

Three.js загружается из jsDelivr, поэтому для первого запуска нужен интернет.

Управление: WASD/стрелки — движение; мышь — обзор (клик по экрану включает захват курсора, после отказа браузера работает перетаскивание); F — фонарик; Z/X/C — слои; 1/2/3 — выбор предмета; E — использовать выбранный предмет; Space — камень; Shift — бег; Escape — пауза.

Q переключает слои по кругу, G выбрасывает выбранный предмет. Камни отвлекают врагов, а миникарта запоминает исследованные области каждого слоя. Найдите ядро воспоминания и затем выход. После гибели эхо повторяет путь предыдущей попытки и может удерживать плиты.

В точках памяти можно нажать E, чтобы сохранить текущий маршрут как эхо без смерти. Бег и шаги создают шум: враги могут пойти на звук. Розовые фрагменты памяти открывают дополнительные детали финального выбора.

Зеркало эха — одноразовый активный предмет: выберите его и нажмите E, чтобы на 5 секунд подсветить ближайших врагов.
