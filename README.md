\# 🔦 ECHO LABYRINTH — Лабиринт Разума



3D хоррор-головоломка от первого лица на Three.js. Вы — человек в коме,

блуждающий по лабиринтам собственного подсознания.



\## 🎮 Механики



\- \*\*👻 Система «Эхо»\*\* — каждая смерть записывает ваш маршрут как призрака

\- \*\*🔦 Свет и тень\*\* — фонарик с ограниченным зарядом

\- \*\*🔄 Три слоя реальности\*\* — Реальность / Память / Кошмар

\- \*\*⚖️ Моральный выбор\*\* — простить или затаить обиду

\- \*\*🎒 Инвентарь на 3 слота\*\*

\- \*\*🐾 Спутник\*\* — светлячок, который боится врагов



\## 🕹️ Управление



| Клавиша | Действие |

|---------|----------|

| WASD | Движение |

| Мышь | Обзор |

| F | Фонарик |

| 1/2/3 | Смена слоя |

| E | Взаимодействие |

| SPACE | Бросить камень |

| SHIFT | Бег |

| ESC | Пауза |
